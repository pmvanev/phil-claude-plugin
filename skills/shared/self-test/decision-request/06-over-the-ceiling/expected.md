# Expected outcome — fixture 06, over the ceiling

**Primary mode:** `OVER-CEILING`. **Full finding set:** `BARE-LIST`, `JARGON-WALL`, `BURIED-ASK`,
`OVER-CEILING`.

The worst single question in this repo's recorded history: **266 words** of question text and option
descriptions, weighing three ways to grant a command board access, behind a sixteen-word lead-in.
Recorded verbatim.

## Why the repaired ceiling needed this

[D4] was rewritten this slice after measurement killed the combined limit. A repaired check with no red
instance is `check-readonly-commands.py`'s first version — written, never called, silently green —
which `CLAUDE.md` makes a standing rule about. This is the real input that fails the new limit.

It also calibrates it. Across 134 recorded questions, 128 fit inside 200 words; the six that do not run
205 to 266. This is the worst of them, failing by 33% — a margin the standard's own remedy closes by
trimming option descriptions, without touching a cost statement. A limit that only the worst instance in
a year's history exceeds by a third is tight rather than arbitrary.

## The one thing this fixture cannot do

`OVER-CEILING` is **not isolated** by any fixture. This ask predates the standard entirely and fails all
four checks, so nothing here proves the ceiling can fire alone. What pins it from the other side is that
01, 04 and 05 pass it — a permanently-firing ceiling check would fail those. Recorded as a known gap
rather than left for a later reader to notice.

Its three `preview` panes are excluded from the count, per the fragment's ruling that a preview is
context. They hold **125** words, so counting them would report this question as **391** rather than 266
— a 47% inflation of the number this repo publishes as its worst case. `preview_words: 125` is recorded
and re-derived, because the first version of this sentence claimed "past 400" and nothing checked it.

## Gate failures

- Splitting the question to make it conform. Then the ceiling has no red instance again.
- Treating 266 as evidence the limit is too low. Six of 134 exceeded it; the other 128 did not.
