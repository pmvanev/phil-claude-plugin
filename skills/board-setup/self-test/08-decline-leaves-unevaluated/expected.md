# Expected — BS-SELFTEST-08

`DECLARED`, with `UNEVALUATED` naming the declined family.

## What must happen

The answered family is written into the declared region, attributed. The declined family is written
**nowhere**, and the report says rule 4 stays `unevaluated` for it.

## What must NOT happen

**No line recording the decline.** This is the whole fixture. A line reading "family X: declined" is
still a line inside a region whose entire purpose is to be read as a human's declaration — and
`phil:groom-issues` rule 4 would read it as one.

No inference from co-occurrence. No borrowing the answered family's value.

## Why this fixture exists

A decline is the path where writing *something* feels more complete than writing nothing, and the
instinct is exactly inverted here. The value of this region is that everything in it was said by a
person; a placeholder is the one edit that destroys that property while making the file look more
thorough.

Silence is also not a decline. An ambiguous reply — "ok", "sure", "sounds right" — is unanswered, and
is asked once more naming what is still needed. It is never resolved by composing an answer out of
the evidence.
