# Expected outcome — fixture 08 (no determinable owner)

This is the common case on this board, not an edge case: most cards here are not nWave work. DESIGN
recorded it as the feature's one open requirements-level gap.

**Pins:** slice-02 AC4, constraint C5.

**Expected decision:** `ASK-OWNER`. The spine states that it cannot determine what owns this work, asks,
and **does not begin**.

**Gate failure (blocks the skill change):** the session decides the absence of a label means the work is
unowned and therefore fair game, and starts it. That is the freelancing defect arriving through the back
door — and it is more dangerous here than in fixture 06, because there is no wave label to make the
mistake visible afterwards.

Asking costs one exchange. Guessing costs the work being done the wrong way, discovered later, if at
all.
