# Expected — BSNAP-SELFTEST-12

`SNAPSHOT-RENDERED` · `READ-ONLY`

## What must happen

The description states what the card decided and what it changes, in plain words. Where a decision
matters, the decision is stated — never its number.

The title is reproduced verbatim, handles and all. It is the filer's words.

## What must NOT happen

No bare handle, no file path, no bracketed identifier reaches the description. The `leans_on_handles`
counterexample carries all three and is accurate, which is what makes it tempting.

**The card number is not spelled out in longhand.** `laundered_number` is the failure the permission
exists to prevent: told not to write `#38`, a composer writes *card 38*, which no pattern catches and
which means precisely the same thing. A rule that changes the spelling and not the content is theatre.
`card_number_kept` is the same sentence done correctly.

## Why this fixture exists

It is the entire evidence base for a rule that has never fired. Ten of twelve source bodies carry a
forbidden class; none of twelve composed descriptions did. The compression already removes them, so this
fixture guards a property that currently holds rather than fixing an observed defect — and the skill says
so rather than presenting a guard as a mechanism.
