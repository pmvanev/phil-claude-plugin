# Expected outcome — fixture 31 (the standard stops at the rendered values)

**Safety core.** A prose standard inside a delimited, regenerated-whole region is legal only because it
applies to sentences the writer **composes**. Applied to values the writer **renders**, it becomes a
second author — the defect the whole-block rule prevents, found live on 2026-08-14 when a refresh
preserved half a region by hand and worked for the wrong reason.

**This block holds all three kinds of text at once**, which is what makes it the discriminating case.

**Expected decision:** `DERIVED-CELLS-UNTOUCHED`.

**Checkable assertions (all must hold):**

1. **Rendered, untouched.** The `⊘` glyph comes from the owner's `deferred` value. No glyph invented,
   substituted or prettified.
2. **The owner's vocabulary survives.** `deferred` is not rephrased to `set aside`, `on hold`, or any
   tighter synonym. The status words belong to `phil:nwave-slice-status`.
3. **Owner-supplied `Notes` reaches the forge intact.** Row 03's `out of scope, per its brief` was
   composed by the owner, so this skill tightens nothing in it.
4. **This skill's own `Notes` sentence IS in scope.** The note recording that a hand-set `done` was
   replaced, and what it said, is composed here — so it is composed against the standard like any other
   sentence this skill writes. **The discriminator is who composed the words, never which column they
   sit in.**
5. **Composed descriptions in the same block ARE composed against the standard.** Row 02's description
   must satisfy fixture 30's assertions 2-6 against its `enumerable_facts`. A mechanism passing this
   fixture by editing nothing fails here, not only in 30.
6. The generation timestamp, the `Order:` line, the `Wave note:` clause and the table scaffolding are
   byte-unchanged by the prose pass.
7. The projected `Why` / `Next` / `Stack`, if present, is byte-identical to what
   `phil:session-handoff` handed over. It is rendered, not composed.

**Gate failure (blocks the skill change):** any rendered value reworded; OR the owner's status vocabulary
replaced with a synonym; OR owner-supplied `Notes` edited for concision; OR this skill's own replaced-value
note left uncomposed on the theory that `Notes` is always the owner's; OR row 02's description left
unedited to satisfy assertion 1.

**Why the pair must resolve opposite ways.** 30 punishes leaving composed sentences alone; 31 punishes
editing what was only rendered, and its assertion 5 punishes editing nothing. Three degenerate mechanisms
— edit everything, edit nothing, publish the shorter candidate — each die on a named assertion. Only the
scope boundary passes, on the pattern fixtures 04 and 11 already set.
