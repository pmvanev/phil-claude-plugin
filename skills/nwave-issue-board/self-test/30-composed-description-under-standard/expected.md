# Expected outcome — fixture 30 (a bounded row can still be padded)

**Safety core.** *Generate into a delimited block* states the bound as a **purpose** — the thirty-second
read — and the skill enforces it as a **count**. Nothing in the skill detects a padded row, so a block can
satisfy every check it has and spend the whole budget anyway. This is the gap the four structural items
have at issue scale, arriving one tier up.

**This fixture supplies a brief and no candidate text**, because the failure it is built from was a
composition failure. A fixture offering two variants would test *selection*, and selection is satisfied by
"publish the shorter string" — the word ceiling `[D5]` refused, smuggled back in as a mechanism.

**Expected decision:** `PROSE-STANDARD-APPLIED`.

**Checkable assertions (all must hold):**

1. The skill names the standard it composed against — `rules/writing.md` — rather than asserting quality
   on its own authority.
2. **Fact coverage.** All three `enumerable_facts` from the manifest appear in the two lines. A tighter
   description that drops one fails; concision is never bought with content.
3. **No expletive construction.** No `there is`, `there are`, `it should be noted that`, `it is important
   to`, `what this does is`. These are the padding forms that survive a two-line limit.
4. **No nominalisation of a verb the brief states as a verb.** `settles` not `makes a determination
   regarding`; `includes` not `has the property of including`.
5. **Active voice**, and the emphatic word last in each line.
6. **Two lines, `<br>`-separated.** The standard tightens sentences; it does not change the shape.
7. **No word count is asserted anywhere in this fixture.** A count would pin one of the standard's eleven
   principles and license the other ten to fail.

**Gate failure (blocks the skill change):** any enumerable fact missing; OR any construction named in 3
or 4 present; OR passive voice where active was available; OR the description published unchanged from a
mechanical restatement of the brief's goal line; OR a word ceiling introduced to satisfy this fixture.

**The two degenerate mechanisms, and where each dies.** *Publish the shorter candidate* — no candidates
exist here, so it produces nothing and fails assertion 2. *Leave every sentence alone* — fails
assertions 3-5. Fixture 31 kills the third: *run a pass over the whole block*, which edits rendered
values. Only the scope boundary in *Compose the block's own sentences against the clarity standard*
passes all three.
