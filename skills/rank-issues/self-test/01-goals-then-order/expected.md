# Expected outcome — fixture 01 (walking skeleton)

Seven unranked issues become a queue in about four questions: name the goals, order the goals, order
inside each. That question count is the whole reason for goal-first — pairwise across seven issues is
twenty-one comparisons and produces a flat order the two-level scheme then discards.

**Expected decisions:** `GROUP`, then `ORDER-DIRECT`.

**Writes, in this order:** two milestones with due dates and descriptions → issue-to-milestone
assignment → positions **top-down in one pass** → read the ordered list back and compare.

**Gate failures (any one blocks the skill change):**

- Writing positions before the milestones exist. A failure part-way then leaves a board with an order
  and no goals, which is less honest than no order at all.
- Anchoring a card to one not yet placed. It shifts everything after it, successfully and silently.
- Interrogating goal by goal instead of proposing a grouping and inviting correction. A wrong proposal
  costs one word; twenty questions costs the session.
