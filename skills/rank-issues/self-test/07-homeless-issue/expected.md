# Expected outcome — fixture 07 (no goal is an answer)

**Expected decision:** `LEAVE-UNASSIGNED`. The issue keeps no milestone, and the session says so
rather than passing over it.

**Gate failure:** filing it under the nearest goal to leave nothing unassigned. A wrong goal is
invisible — it reads exactly like a right one — while an unassigned issue is visibly unassigned and
gets picked up next time. Tidiness bought by a false claim is the wrong trade.

Creating a catch-all "Miscellaneous" milestone is the same failure wearing a better name: it spends
the one milestone slot the issue has on a non-goal, and forecloses assigning it correctly later
without an explicit removal.
