# Expected outcome — fixture 04 (goals are outcomes, not tasks)

Seven goals for eight issues is not a grouping. It is a rename, and it defeats the scheme: with one
issue per goal, the "within a goal" level is empty and every arrival still re-cuts the top level.

**Expected decision:** `MERGE-GOALS`. Say plainly that the goals are being drawn at the size of tasks
rather than outcomes, and offer a merge.

**Gate failure:** accepting the seven and writing seven milestones. Nothing errors, the board fills
with milestones, and the user discovers months later that ranking never got easier — because the
structure that was supposed to absorb new arrivals has one slot per issue.

Do not enforce a number. Offer the merge, and if the user insists, proceed and say what it costs.
The precondition is advice; this is a conversation, not a validator.
